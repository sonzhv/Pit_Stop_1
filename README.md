# Pit_Stop_1
A task for Digital Literary Studies. This repository contains all three assignments.

For the Assignment 1, I created a Markdown document using a section from “Crime and Punishment” by Fyodor Dostoevsky. I used [Dillinger.io](https://dillinger.io/) to format the text with Markdown syntax. I added headings, cursive and bold text. Then I saved the file as “crime_and_punishment.md” and uploaded it to my GitHub repository.

For the Assignment 2, I used the Internet Archive. I downloaded “Crime and Punishment” in [PDF format](https://archive.org/details/crimepunishment00dostiala/page/n7/mode/2up) and performed OCR using Google Drive (“Open with Google Docs”). After cleaning the text (removing formatting and OCR mistakes), I converted it into Markdown format. Finally, I uploaded the cleaned Markdown file to my GitHub repository.

For the Assignment 3, I created a small dataset of my favourite books using Microsoft Excel. I included columns for the title, author and year. After that, I exported the sheet in .csv format and uploaded it to my GitHub repository.
